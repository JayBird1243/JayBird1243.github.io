How it works

Every random choice comes from the seed. The renderer splits it into 8-digit slices and starts a separate random stream from each, so the star count, star placement and nebula don't disturb each other.

Step 1Seed to random numbers

I use Mulberry32, a small, fast pseudo-random generator. Each stream starts from its own 8-digit slice of the seed, read as a 32-bit number.

function prng(seed, stream) {
  var start = (stream * 8) % 32;
  var state = parseInt(seed.substring(start, start + 8), 16) >>> 0;
  return function () { /* Mulberry32 step: 0 ≤ n < 1 */ };
}
var nodeRng  = prng(seed, 0);
var countRng = prng(seed, 1);
var starRng  = prng(seed, 2);

Step 2Uniform to normal

The generator gives uniform numbers. The Box–Muller transform turns two of them into one normally distributed number. Ordinary star sizes (1 to 5) use mean 2 and standard deviation 1.426. The star count is normal too: every seed has a full sky of about 600 stars, and each canvas draws the share of them that fits its size.

function normal(rng, mean, sd) {
  var u = 0, v = 0;               // two uniform samples
  while (u === 0) u = rng();
  while (v === 0) v = rng();
  return Math.sqrt(-2 * Math.log(u))
       * Math.cos(2 * Math.PI * v) * sd + mean;
}
size  = clamp(floor(normal(starRng, 2, 1.426)), 1, 5);
base  = normal(countRng, 600, 132);        // stars in the full sky
shown = base * (density * area) / 600;     // share this canvas draws

Step 3Big stars

Sizes 6 to 10 are rare. They are drawn in colour with a glow, and sizes 8 and up get spikes. Each of the 600 or so stars in the full sky rolls once for a big size, with a fixed chance per star. A seed has the same big stars on every screen, and because each star rolls on its own, one sky can have several.

A sky with a size 8 or bigger star shows a small note when the star is on screen.

// skies per star of each size, on average
var odds = { 6: 2, 7: 15, 8: 100, 9: 500, 10: 1000 };

// chance per star = (1 / odds) / stars in a full sky
function chance(size) {
  return (1 / odds[size]) / 600;
}

var roll = starRng();             // one roll per star
var size = ordinarySize();        // 1 to 5, from step 2
var upTo = 0;
for (var big = 10; big >= 6; big--) {
  upTo += chance(big);
  if (roll < upTo) { size = big; break; }
}

Step 4Nebula colours from the seed

Three to six large, soft radial gradients make the nebula. Each colour comes straight from pairs of seed digits: they pick one of four base hues, nudge it by up to 12°, and set saturation, lightness and opacity. The star slice is skipped, so changing it changes the stars and nothing else.

var d = seed.substring(0, 16) + seed.substring(24);  // skip the star slice
var a = parseInt(d.substr((i * 3) % 22, 2), 16);     // 0–255
var b = parseInt(d.substr((i * 5 + 7) % 22, 2), 16);
var c = parseInt(d.substr((i * 7 + 13) % 22, 2), 16);
var hue   = [38, 215, 265, 12][(a + b * (i + 1)) % 4] + (c % 24) - 12;
var sat   = 45 + (b % 36);          // %
var light = 17 + (c % 13);          // %
var alpha = 0.22 + (a % 40) / 170;

Step 5Seeds one star apart

Two random seeds give unrelated skies, so swapping between them looks like a cut. But Mulberry32 is a counter pushed through a mixer, and the counter goes up by the same amount on every draw. Each star uses five draws. Add five of those steps to the star slice and you get the seed whose star list starts one star later: the same sky, minus its first star, plus one new star at the end.

The animation walks that chain. At each step one star fades out and the new one flares in. The nebula has no neighbours like this, so every few seconds it gets new digits and the blobs drift to the new layout. The slider sets how many seeds it steps through each second, from 0.25 to 20.

var STEP = 0x6D2B79F5;   // Mulberry32 counter step

// x, y, big roll, and two draws for the size
var DRAWS_PER_STAR = 5;

function nextSeed(seed) {
  var state = parseInt(seed.substr(16, 8), 16);
  state = (state + Math.imul(STEP, DRAWS_PER_STAR)) >>> 0;
  return seed.substr(0, 16) + hex8(state) + seed.substr(24);
}
