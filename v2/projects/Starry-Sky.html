How it works

Every random choice comes from the seed. The renderer splits it into 8-digit slices and starts a separate random stream from each, so the star count, star placement and nebula don't disturb each other.

Step 1Seed to random numbers

I use Mulberry32, a small, fast pseudo-random generator. Each stream starts from its own 8-digit slice of the seed, read as a 32-bit number.

function prng(seed, stream) {
  var start = (stream * 8) % 32;
  var state = parseInt(seed.substring(start, start + 8), 16) >>> 0;
  return function () { /* Mulberry32 step: 0 ≤ n < 1 */ };
}
var nodeRng  = prng(seed, 0);
var countRng = prng(seed, 1);
var starRng  = prng(seed, 2);

Step 2Uniform to normal

The generator gives uniform numbers. The Box–Muller transform turns two of them into one normally distributed number. Star sizes use mean 2 and standard deviation 1.426. The star count is normal too, around a mean that grows with the canvas area.

function normal(rng, mean, sd) {
  var u = 0, v = 0;               // two uniform samples
  while (u === 0) u = rng();
  while (v === 0) v = rng();
  return Math.sqrt(-2 * Math.log(u))
       * Math.cos(2 * Math.PI * v) * sd + mean;
}

Step 3Nebula colours from the seed

Three to six large, soft radial gradients make the nebula. Each colour comes straight from pairs of seed digits: they pick one of four base hues, nudge it by up to 12°, and set saturation, lightness and opacity.

var a = parseInt(seed.substr((i * 3) % 30, 2), 16);  // 0–255
var b = parseInt(seed.substr((i * 5 + 7) % 30, 2), 16);
var c = parseInt(seed.substr((i * 7 + 13) % 30, 2), 16);
