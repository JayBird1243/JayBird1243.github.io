Line Temperature HMI

An Ignition screen that gives operators a live picture of a GWK water temperature-control unit: process temperatures, sequencer step and a colour-coded piping mimic, with data from a Siemens S7-300. The PLC program already existed. I did the tag integration and the screen.

SCADA
Inductive Automation Ignition
PLC
Siemens S7-300 (existing program)
Equipment
GWK water temperature-control unit
My scope
Screen design and tag integration
  • Machine state at a glance. Pipe segments on the mimic recolour with live state, so an operator can see where the unit is in its program without reading the sequencer.
  • Trends beside the numbers. Temperature-over-time charts sit next to the sequencer step list, so temperatures are easy to check.
  • Siemens-to-Ignition integration. I linked the S7-300 tags into Ignition. The PLC program was existing and not mine.
01

Problem

The GWK unit still used obsolete monitors. I was asked to build a new HMI to replace them, working with the existing PLC program.

02

What I built

  1. Tag integration. Connected Ignition to the S7-300 and mapped the temperature, state and sequencer tags the screen needed.
  2. Piping mimic. A schematic of the unit with each pipe segment bound to live tags, recolouring with system state.
  3. Sequencer display. Current step and step list, for checking the program as it runs.
  4. Trends. Live temperature-over-time charts for spotting drift and confirming setpoint response.
  5. Manual heating control. For setup and maintenance, behind a confirmation.
03

Design decisions

  • Mimic for pattern recognition, trends for diagnosis. The mimic shows whether things look normal. The charts show when that changed.
  • Every colour means something. Each colour change on the mimic maps to a real PLC state.
  • Clear scope. I did not write the PLC program. My part was the data path and the operator's view of it.
04

What I took from it

Much of HMI design is deciding what to leave off. This was my first time using Ignition, and I was surprised how flexible and customizable it is.
