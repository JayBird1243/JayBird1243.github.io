Material Loss Tracking

Material was going missing on a production line and nobody could say where. I built the tool that found out: the HMI, database procedures, PLC networking and operator training.

Role
Owned end to end
HMI
TwinCAT HMI on a Linux-based kiosk
Backend
SQL stored procedures
Rollout
Operator training, run by me
  • I designed the HMI, created the stored procedures with IT, networked the panel to the main line PLC and trained the operators.
  • Every loss is logged with a reason at the station where it happened, and engineering can query it.
  • Reporting a loss takes two taps, from a fixed list of reasons.
01

Problem

Valuable material was being lost along the line for unknown reasons. Existing systems only recorded a "scrapped" status, with no reason code. Engineering needed traceable data to improve the process.

02

What I built

  1. A reporting HMI where the operator picks a loss reason in two taps. If reporting is a chore, operators stop doing it.
  2. New SQL stored procedures for inserts and reporting, created with IT, so engineering can query losses by station, reason and shift.
  3. The network path between the panel and the main line PLC, which supplies station and context data.
  4. Database messaging from the HMI. A send that times out or is not acknowledged raises an error.
  5. Operator training sessions, which I planned and ran.
03

Design decisions

  • Terminals sit at the station, so a loss is reported where it happens.
  • Reasons come from a fixed list, because free text can't be aggregated.
  • The screen follows the line's colour rules: no red or yellow on a non-safety screen, and fully saturated colours that read the same on mismatched monitors.
04

Result

Engineering used the data to find the most common causes of material loss and changed the process to reduce them.

05

What I took from it

I owned the whole project from start to finish, which taught me a lot about project management. I worked with people I normally wouldn't, and managed parts of a project I usually wouldn't be involved in.
