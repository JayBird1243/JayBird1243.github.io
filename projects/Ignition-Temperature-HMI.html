Line Temperature HMI

An Ignition screen that gives operators a live picture of a GWK water temperature-control unit — process temperatures, trends and a colour-coded piping mimic — with data pulled from a Siemens S7-300.

Problem context

One of the existing HMIs broke. I was tasked with programming a new HMI to replace it, and integrate with the existing PLC program.

What I built Ignition

  1. Tag integration. Connected Ignition to the S7-300 and mapped the temperature and state tags the screen needed.
  2. Piping mimic. A schematic of the unit with pipe segments bound to live tags, recolouring with system state.
  3. Trends. Real-time temperature-over-time charts for spotting drift and confirming setpoint response.
  4. Manual heating control. Available for setup and maintenance when needed, behind a confirmation.

Design decisions why

  • Diagram for pattern recognition, trends for diagnosis. The mimic answers "is it normal?"; the charts answer "since when?".
  • Colour carries state Every colour change on the mimic maps to a real PLC state.
  • Scope. I did not write the PLC program; the value I added was the data path and the operator's view of it.

What I took from it practice

The project taught me how much of HMI design is deciding what to leave off. This was my first experience with Ignition, and I was surprised by the amount of flexibility and customization that was available.
