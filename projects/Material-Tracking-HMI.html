Material Loss Tracking

Material was going missing on a production line and nobody could say where. I built the tool that found out — HMI, database procedures, PLC networking and operator training, end to end.

  • 02Turned "material is going missing" into data. Every loss is now logged with a reason, at the station where it happened, and is queryable by engineering.

Problem context

Valualbe material was being lost along the line for unknown reasons. Existing systems simply recorded 'scrapped' statuseswith no reason code. The engineers needed traceable data to improve the process.

What I built scope

  1. Reporting HMI. A low-friction flow: pick the loss reason in two taps. If reporting is cumbersome, operators stop reporting, and the data is worthless.
  2. Database layer. Corresponded with IT to create new SQL stored procedures for inserts and reporting, structured so engineering can query losses by station, reason and shift.
  3. PLC networking. Connected the HMI to the main line controller for station and context data; configured the network path between panel and PLC.
  4. Resilient messaging. Queue-and-retry logic around every database send so the screen stays responsive and no report is dropped.
  5. Training. I ran planned and ran the operator training sessions to get them acquainted with the tool.

Design decisions why

  • Report where the loss happens. Terminals sit at the station, for easy operator access.
  • Reasons are a fixed list, not free text. Free text cannot be aggregated; a curated list can be easily queried and analyzed.
  • Same colour discipline as the rest of the line: no red or yellow on a non-safety screen, high-contrast primaries for mismatched monitors.

Outcome result

Engineering was able to identify the most common reasons for material loss, and improve the process to reduce losses. Material loss was reduced by 30% post optimization.

What I took from it practice

I was given the opportunity to own the entire project from start to finish, which provided a valuable leanring experience in project management. I was able to interface with people I normally wouldn't connect with, and got to manage parts of the project that I normally wouldn't be involved in.
